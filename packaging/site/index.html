Linux

GTK4 with an OpenStreetMap map. Signed package repositories for x86_64 and ARM — updates arrive with your system ones.

FFedora 45

Add the repository and install:

sudo dnf config-manager addrepo \
  --from-repofile=@URL@/geo-photo-library.repo
sudo dnf install geo-photo-library

UUbuntu 24.04 / 26.04

Add the signing key and the repository, then install:

sudo install -d /etc/apt/keyrings
curl -fsSL @URL@/key.gpg \
  | sudo tee /etc/apt/keyrings/geo-photo-library.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/geo-photo-library.gpg] @URL@/deb $(. /etc/os-release && echo $VERSION_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/geo-photo-library.list
sudo apt update && sudo apt install geo-photo-library

Prefer a single file? RPM and DEB packages are attached to every release. Building from source is described in the README.
